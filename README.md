## JavaFX-Calculator
Project tugas kalkulator sederhana menggunakan **JavaFX** dan **Scene Builder**.

## Deskripsi
Aplikasi ini merupakan kalkulator sederhana yang dibuat menggunakan bahasa pemrograman Java dengan JavaFX sebagai antarmuka (GUI). Project ini masih dalam tahap pengembangan dan beberapa fungsi masih perlu diperbaiki serta dikembangkan lebih lanjut.

## Fitur
Fitur yang sudah tersedia:

- Input angka 0–9
- Operasi penjumlahan (+)
- Operasi pengurangan (-)
- Operasi perkalian (*)
- Operasi pembagian (/)
- Operasi Persen (:)
- Menampilkan hasil perhitungan (=)
- Menghapus seluruh angka (AC)
- Menghapus sebagian angka (<x)
- Tanda Positive/Negative (+/-)

## Pengembangan Selanjutnya
Beberapa fungsi masih perlu diperbaiki atau dikembangkan, seperti:
- Tombol **AC (All Clear)** yang masih perlu diperbaiki
- Tombol **hapus satu karakter (<x)**
- Tombol **+/−**
- Perbaikan fungsi desimal
- Penyempurnaan tampilan dan fungsi kalkulator

## Teknologi yang Digunakan
- Java
- JavaFX
- Scene Builder
- NetBeans IDE

## Cara Menjalankan Aplikasi
1. Clone atau download repository ini.
2. Buka project menggunakan **NetBeans IDE**.
3. Pastikan JavaFX sudah dikonfigurasi pada project.
4. Jalankan file `Calculator.java`.
5. Aplikasi kalkulator akan muncul.
